# HRanalysis – Next Phase

## Recruitment workflow
- Request creation supports recruitment, training, trial and evaluation.
- Each request stores weighted requirements and required/optional flags.
- Engineering roles can receive the standard engineering requirement library.
- Candidates receive a unique share link and submit their own data.
- Candidate scores are stored per requirement.
- Overall compatibility is calculated from requirement weights.
- Required gaps are shown separately from general weaknesses.

## Planned improvements
1. Add authenticated HR users and tighten public RLS policies.
2. Add request editing after creation.
3. Add candidate filtering and ranking by compatibility.
4. Add interview scheduling and interview evaluation.
5. Add exportable candidate/request reports.
6. Add dashboard KPIs for open requests, candidates and hiring funnel.
